# Форматирование Vue-шаблонов

Применять при написании и ревью Vue SFC, а также при массовом форматировании шаблонов.

## Основной принцип

**Prettier — источник истины по форматированию.** Не менять его результат вручную ради более
компактного кода. Не отключать правила многострочного содержимого ради сокращения строк.

## Интерполяции

Если интерполяция многострочная, открывающая `{{` и её содержимое находятся на новой строке,
а закрывающая `}}` — на следующей.

```vue
<!-- Неправильно -->
<span v-if="staff?.email" class="user-menu__email">{{ staff?.email }}</span>

<!-- Неправильно -->
<span v-if="staff?.email" class="user-menu__email">{{
  staff?.email
}}</span>

<!-- Правильно -->
<span v-if="staff?.email" class="user-menu__email">
  {{ staff?.email }}
</span>
```

Допускается короткая конструкция на одной строке, если она не требует переноса по правилам
форматирования проекта:

```vue
<span>{{ title }}</span>
```

Не разрывать интерполяцию так, чтобы открывающая `{{` оставалась на предыдущей строке отдельно от
её содержимого.

## Смысловые блоки

Оставлять пустую строку между независимыми секциями, крупными элементами форм, карточками,
таблицами и повторяющимися блоками.

```vue
<template>
  <header class="profile-header">
    <h1>Профиль</h1>
  </header>

  <section class="profile-details">
    <ProfileNameForm />
  </section>

  <section class="profile-security">
    <ProfilePasswordForm />
  </section>
</template>
```

Не объединять несколько независимых секций в сплошной текст. Не добавлять пустые строки между
строками одного простого логического блока.

## Именованные слоты

Оставлять пустые строки вокруг содержимого именованных слотов и между соседними слотами.

```vue
<Card>
  <template #header>
    <h2>Настройки</h2>
  </template>

  <template #content>
    <SettingsForm />
  </template>

  <template #footer>
    <Button type="submit">Сохранить</Button>
  </template>
</Card>
```

Внутри слота также применяются правила разделения смысловых блоков.

## Атрибуты и элементы

- Длинные списки атрибутов переносить по одному атрибуту на строку.
- Не переносить короткие нативные пустые элементы специально: `<br>`, `<img>`, `<input>`.
- Самозакрывающиеся компоненты и нативные пустые элементы оформлять согласованно с Prettier.
- Вычисления и сложные выражения выносить в `computed`, а не растягивать их в шаблоне.

## Запрещено

- Сжимать шаблон ради уменьшения числа строк.
- Оставлять многострочную интерполяцию на одной строке с тегом.
- Удалять пустые строки между независимыми секциями и слотами.
- Отключать `vue/multiline-html-element-content-newline` и
  `vue/singleline-html-element-content-newline`, если это приводит к конфликту с Prettier.

## Проверка

1. Запустить Prettier на изменённых SFC.
2. Убедиться, что интерполяции и слоты соответствуют примерам выше.
3. Проверить, что между независимыми блоками остались пустые строки.
4. Запустить typecheck и релевантные компонентные тесты.
